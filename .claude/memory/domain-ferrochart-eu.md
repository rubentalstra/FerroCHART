The public domain is **ferrochart.eu**, registered by the owner on 2026-09-06
at Vimexx with `ns.zxcs.nl`, `ns.zxcs.be`, and `ns.zxcs.eu`, matching
ferrohealth.eu, ferroehr.eu, ferroterm.eu, and ferrobridge.eu.

**Why the name is not FerroFORM:** ferroform.eu was already registered
(GoDaddy, Cloudflare nameservers, no A record and no site, so parked). "Ferro
form" is also a plausible metal-forming trademark, so a near-identical name was
a real collision risk. CHART was chosen because charting is the clinician's own
word for entering and reading data, and it covers both directions the product
works in.

**How to apply:**

- The domain is a Pages setting mirroring ferroterm.eu, never a committed
  `CNAME` file.
- Never write FerroFORM in this repository. If a document needs to explain the
  name, it says what this file says.
